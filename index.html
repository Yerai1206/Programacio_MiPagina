Documentación Técnica

Decisiones de Arquitectura (ADR)

Justificación técnica de las herramientas elegidas para el desarrollo de esta práctica académica.

ADR-001

Sistema de Formularios (Web3Forms)

Contexto: Se requería un formulario funcional en un entorno puramente Frontend antes de implementar el Backend con PHP.

Decisión: Utilizar la API gratuita de Web3Forms mediante `fetch` de JavaScript.

Justificación: Permite enviar correos reales y configurar un auto-responder automático de forma inmediata, cumpliendo el requisito de interactividad de la rúbrica sin requerir servidor propio.

ADR-002

JavaScript y CSS Nativos

Contexto: Evitar la sobrecarga de herramientas y demostrar comprensión real del código.

Decisión: Descartar frameworks (como Bootstrap o React) a favor de CSS Custom Properties y Vanilla JS modular.

Justificación: Mantiene el proyecto ligero, facilita la adaptación del modo oscuro y asegura que cada línea escrita proviene de un aprendizaje directo.
